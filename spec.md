# SPEC: Локальный голосовой ассистент "Jarvis"

Spec Kit CLI зависал на интерактивном промпте в неинтерактивной среде — сформирован вручную (разрешено правилами `/allforme` при недоступности Spec Kit).

## Цель
Полностью локальный (без обязательного интернета, кроме явного веб-поиска), бесплатный голосовой ассистент на Windows 11 ПК пользователя, вызываемый кодовым словом "Jarvis".

## Окружение
- Windows 11 Pro, i5-10400F (6c/12t), 16GB RAM, RTX 3060 12GB VRAM (реальный объём, не верить WMI AdapterRAM).
- Диск C: ~20.8GB свободно — не использовать для тяжёлых файлов.
- Диск D: ~124.6GB свободно — venv, модели, кэши сюда. Проект: `D:\claude code prj\3\jarvis`.
- Ollama v0.34.0 уже установлен, модели `gemma4:2b`, `gemma4:26b`, `nomic-embed-text` уже скачаны. Переключить `OLLAMA_MODELS` на диск D.

## Функциональные требования
1. ~~Wake word "Jarvis" через Picovoice Porcupine~~ — **ИЗМЕНЕНО при синтезе** (см. `RESEARCH.md`, `DECISIONS.md`): бесплатный тариф Porcupine закрылся 30.06.2026. Используется open-source **openWakeWord** с готовой моделью `hey_jarvis`, постоянное прослушивание, без ключей доступа. Фактическая кодовая фраза — **"Хей, Джарвис" (hey jarvis)**, а не голое "Jarvis".
2. Русский язык: STT — faster-whisper (GPU), TTS — Silero (русский голос).
3. LLM — Ollama, модель с tool-calling ~7-8B, помещающаяся в 12GB VRAM целиком (подобрать в Фазе research). `gemma4:26b` — отдельный "режим глубокого анализа" по явной фразе.
4. Белый список действий: открыть приложение/файл, открыть сайт, веб-поиск (DuckDuckGo, без ключа) с озвучкой, чтение/запись файлов на диске D (**расширено** с "рабочих папок проекта" до всего диска D — явный запрос пользователя, см. `DECISIONS.md` п.10), безопасные dev-команды (`git status`, `npm test` — не произвольный shell), громкость, блокировка экрана, проводник.
4a. **Расширено при синтезе** (явный запрос пользователя, см. `DECISIONS.md` п.10): установка Python-пакетов (`install_package`, через pip), установка программ (`install_app`, через winget), и редактирование/перезапуск собственного кода (`write_code_file` + `restart_self`) — только по имени пакета/программы, провалидированному маской (без пробелов/shell-метасимволов/версий/URL), без `shell=True`.
5. **Запрещено физически** (не через промпт, а через отсутствие соответствующего кода): удаление файлов, форматирование, выключение/перезагрузка ПК, реестр, деинсталляция, произвольный shell. Умный дом — вне scope.
6. Личность: сдержанный, суховато-ироничный дворецкий, обращение на "вы".
7. Фоновая служба: автозапуск при логоне (Планировщик заданий), скрытое окно, restart-on-failure, лог действий `logs/action.log`.
8. Доп.: barge-in, звуковой сигнал пробуждения, трей-иконка (сон/слушаю/думаю), текстовый fallback, `config.yaml`.

## Definition of Done
- Автозапуск и фоновая работа без консольного окна.
- Голосовая команда → голосовой ответ на русском за разумное время.
- ≥3 задокументированных сквозных сценария в `MANUAL_TEST.md`, включая отказ на запрещённое действие.
- Ни один модуль не передаёт непровалидированную строку модели в `os.system`/`subprocess`.
- Логи пишутся и читаемы.
- Все тяжёлые файлы на диске D.

## Вне scope (v1)
Умный дом/IoT, обучение кастомного wake word, облачные LLM, GUI кроме трей-иконки.
