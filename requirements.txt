# готовые wheel-сборки не сразу для новых версий Python — на слишком новом
# Python pip пытается собрать их из исходников, для чего нужен компилятор C

# на Python 3.14 сборка numpy падает с "Unknown compiler(s)".
#
# ВАЖНО (GPU, RTX 3060 12GB): сначала поставь CUDA-сборку torch под
# установленный у тебя CUDA toolkit, например:
#   pip install torch --index-url https://download.pytorch.org/whl/cu121
# Без этого torch поставится CPU-only и STT/TTS будут работать медленнее
# (код сам определяет отсутствие CUDA и откатывается на CPU, не падая).
